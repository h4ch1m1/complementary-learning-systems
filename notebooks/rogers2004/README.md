# Rogers et al. (2004)

- `tutorial.ipynb`: complete Colab lesson, with the article, calculations, interactive comparisons and optional training.
- `semantic_deterioration.ipynb`: original-settings mechanism reconstruction.
- `tuning_results.ipynb`: audit of the optimized checkpoint.
- `rogers_model.py`: recurrent model, training and task evaluation.
- `build_tutorial.py`: tutorial generator.
- `test_model.py` and `test_tuning.py`: numerical and regression checks.

Saved checkpoints and measurements are under `outputs/rogers2004/`. Methodological details are in `notes/ROGERS2004_NOTES.md`.
